# SimpleComboSystem
A test project for a simple combo system

This is a test project for learning how animation, animation montages and anim notifies work in Unreal Engine 5.7 with Blueprint

I started with two video tutorial, each one with its own approach: 
- the first was using one animation for the entire combo, that needed to be interrupted when the player's inputs stop. I've implemented it in the component "AC_SimpleComboSystem_OneAnim";
- the second was using a different animation for each blow. I've implemented it in the component "AC_SimpleComboSystem"
